Fineprint — app map

Follow one action — “Read the fine print” — through the code.

1. The button

public/app.js — the #input form's onsubmit posts to /api/analyze.

2. The server

server.js → handleApi → loadSource (fetches a URL or uses pasted text) → analyze().

3. Reading

lib/analyze.js uses lib/llm.js when a key is set (falls back to lib/heuristics.js on any error), then finalize().

4. The kernel: verification

lib/verify.js → verifyQuote(source, quote) normalizes spacing and curly quotes and requires an exact match. That's what turns the badge green or amber.

Practice to reuse

When an AI produces facts from a document, make it return the evidence too — and check the evidence with code, not with another AI call.
